新增

  • “设置 › 关于”会显示测试版的到期时间和剩余天数。
  • 助手的 CLI 智能体（Claude Code、Codex、Gemini CLI）现在会启动各自当前的 ACP 适配器；用旧预设创建的账户会自动改用新命令。

改进

  • 历史记录越来越多时，发送依然迅速：发送不再扫描整个历史记录，也不再等待磁盘（含 20,000 条记录的历史记录，写入速度提高到原来的四倍）。
  • 新工作区自带 .gitattributes 文件，因此 Git 绝不会更改其中文件的行尾，导出时也会保留它。

修复

  • 你正在编辑的请求如果在 Echolot 之外被删除，不会再被写回：会出现一个提示栏，提供“重新保存”或“丢弃”。
  • 环境名称和机密值会在你离开输入框时存储，并去除首尾空白；环境也不能再没有名称。
  • 在一个窗口中更改的全局变量会同步到所有打开的窗口。
  • 停止发送会同时停止跟踪其响应；重新连接 WebSocket、Socket.IO 或 MQTT 会话时，绝不会关闭较新的连接。
  • 新建的 MCP 和 gRPC 调用可以撤销；流程中的询问和 MCP 输入请求会依次排队等待，不再相互替换。
  • “允许访问”只会授予 Echolot 所请求的那个文件。
  • 快速连续打开多个规范时，会显示最后打开的那个。
