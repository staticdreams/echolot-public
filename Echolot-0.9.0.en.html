New

  • Mocks stream: routes play server-sent events, take WebSocket and Socket.IO connections, and a mock can run an MQTT broker beside its port. JavaScript routes take sockets too.
  • gRPC requests can run as live calls: send messages one at a time and see answers as they arrive.
  • Webhooks can be signed: a sender's HMAC signature lets a delivery in without the token, and tokens can be rotated.
  • Agents make every kind of request, set OAuth 2.0 client-credentials auth, and keep WebSocket, Socket.IO and MQTT sessions open across calls (the new Sessions toolset, with Stop in the Agents popover).
  • Agents can propose a script: you see the diff and choose Save and Trust or Decline.
  • Suites check WebSocket, Socket.IO and MQTT sessions: checks and captures on received messages, message counts and closes, and a request can stop listening once it has what it needs.
  • The Tests page runs checks with Run and Run All; the Runner filters its results by Passed and Failed.
  • The command palette (⌘K) finds flows, specs, mocks and MCP servers by name.
  • GraphQL requests can share one query file, and a request can name its own spec for openapi checks.

Improved

  • Released builds no longer ask for Keychain access: the app and the command-line tool share their secrets. Variable editors warn about short secrets and ordinary words.
  • Schedules and webhooks can name their environment and never run in a protected one they didn't name. `echolot mcp serve` moves to the app when the app opens the workspace.
  • `echolot run` keeps captured values in memory unless --save-captures, and never sends a request whose variables don't resolve.

Fixed

  • Fixed gRPC reflection with relative type names, MQTT brokers that only speak 3.1.1, and a few layouts that ran past their pane in French and Russian.
