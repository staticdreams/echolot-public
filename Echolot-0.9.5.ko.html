새로운 기능

  • 플로가 결과를 파일로 저장합니다. 파일 쓰기 블록은 JSON, JSON Lines, CSV, TSV, 통합 문서, Markdown 또는 HTML 페이지를 쓰며, 파일이 이미 있으면 뒤에 추가하거나 둘 다 유지할 수 있고, 저장할 위치를 물어볼 수도 있습니다.
  • 플로에 모델에게 질문 블록이 추가되었습니다. 이 블록은 설정 › 어시스턴트의 모델에게 한 번 질문합니다. 블록을 제목 아래에 그룹으로 묶고 색상을 지정할 수 있습니다.
  • 요청의 GraphQL 스키마로 응답을 검사할 수 있습니다.
  • MCP 서버 페이지에 리소스 템플릿이 표시되며, 변수마다 입력 필드가 있습니다. 서버의 샘플링 요청에 사용자의 모델로 답할 수 있으며, 답변이 서버로 돌아가기 전에 직접 읽어 볼 수 있습니다.

개선됨

  • WebSocket, Socket.IO 및 GraphQL 구독이 업그레이드와 함께 요청의 인증을 보냅니다(Hawk, OAuth 1.0, EdgeGrid, AWS, Digest). MQTT 게시에 5.0 속성이 포함됩니다.
  • User-Agent, Accept, Cookie 같은 자동 헤더를 요청마다 끌 수 있습니다. 설정 탭에는 요청 종류에서 사용하는 항목만 표시됩니다. cURL로 복사와 코드 생성에 Hawk, OAuth 1.0 및 EdgeGrid 서명이 포함됩니다.
  • 어시스턴트의 도구 호출이 입력창 뒤의 트레이에 표시됩니다. 대화에는 주고받은 말만 남습니다.
  • 작업 공간의 사본은 원본의 비밀 값과 권한을 사용하기 전에 먼저 묻습니다.
  • 빠른 보내기(메뉴 막대 패널)가 제거되었습니다. 단축어 동작은 그대로 유지됩니다.

수정됨

  • 두 차례의 보안 감사: 악의적인 응답, 명세, 서버가 더 이상 Echolot을 충돌시키거나 멈추게 할 수 없고, 리디렉션이 더 이상 비밀 값을 다른 호스트로 전달하지 않으며, 에이전트는 안전 모델이 허용하는 것만 볼 수 있습니다.
  • 다시 불러오거나 종료할 때 편집 내용이 사라지는 문제, 큰 JSON과 긴 줄이 느리게 열리는 문제, 마린에서의 시트 문제, 안내 투어 문제를 수정했습니다.
