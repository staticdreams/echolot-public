New

  • Settings › About shows when a beta build expires, with the days left.
  • The Assistant's CLI agents (Claude Code, Codex, Gemini CLI) start their current ACP adapters; accounts made from an old preset move to the new command by themselves.

Improved

  • Sending stays fast as history fills up: a send no longer scans the whole history or waits for the disk (a 20,000-entry history fills four times faster).
  • New workspaces come with a .gitattributes, so Git never changes the line endings of their files, and exports keep it.

Fixed

  • A request deleted outside Echolot while you edit it is no longer written back: a bar offers Save Again or Discard.
  • Environment names and secret values are saved when you leave the field, trimmed, and an environment can no longer be left without a name.
  • Global variables changed in one window reach every open window.
  • Stopping a send stops following its response, and reconnecting a WebSocket, Socket.IO or MQTT session never closes the newer connection.
  • New MCP and gRPC calls can be undone, and flow prompts and MCP input requests wait their turn instead of replacing each other.
  • Allow Access grants only the file Echolot asked for.
  • Opening several specs quickly shows the last one opened.
