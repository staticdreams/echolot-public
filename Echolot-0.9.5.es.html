Nuevo

  • Los flujos guardan resultados en archivos: el bloque Escribir archivo escribe JSON, JSON Lines, CSV, TSV, un libro de cálculo, Markdown o una página HTML, puede añadir al final o conservar ambos cuando el archivo ya existe, y puede preguntarte dónde guardarlo.
  • Los flujos tienen un bloque Preguntar a un modelo, que pregunta una vez al modelo de Ajustes › Asistente. Los bloques se pueden agrupar bajo un título y colorear.
  • Las respuestas se pueden comprobar con el esquema GraphQL de la solicitud.
  • La página Servidores MCP muestra las plantillas de recursos, con un campo para cada variable. Tu modelo puede responder a la petición de muestreo de un servidor, y tú lees la respuesta antes de que se devuelva.

Mejorado

  • WebSocket, Socket.IO y las suscripciones GraphQL envían la autenticación de la solicitud con la actualización de la conexión (Hawk, OAuth 1.0, EdgeGrid, AWS, Digest). Las publicaciones MQTT llevan propiedades de MQTT 5.0.
  • Las cabeceras automáticas, como User-Agent, Accept y Cookie, se pueden desactivar en cada solicitud. La pestaña Ajustes muestra solo lo que usa el tipo de la solicitud. Copiar como cURL y Generar código incluyen las firmas Hawk, OAuth 1.0 y EdgeGrid.
  • Las llamadas a herramientas del Asistente están en una bandeja detrás del campo de mensaje. La conversación conserva solo las palabras.
  • Una copia de un espacio de trabajo pregunta antes de usar los secretos y permisos del original.
  • Se elimina Envío rápido (el panel de la barra de menús). Las acciones de Atajos se mantienen.

Corregido

  • Dos auditorías de seguridad: las respuestas, especificaciones y servidores hostiles ya no pueden hacer que Echolot se cierre inesperadamente ni que se bloquee, las redirecciones ya no llevan secretos a otros hosts y los agentes solo ven lo que permite el modelo de seguridad.
  • Corregidos: las ediciones que se perdían al recargar o salir, la apertura lenta de JSON grandes y de líneas largas, las hojas en Marine y el recorrido guiado.
