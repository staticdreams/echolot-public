New

  • Flows save results to files: the Write File block writes JSON, JSON Lines, CSV, TSV, a workbook, Markdown or an HTML page, can append or keep both when the file exists, and can ask you where to save.
  • Flows get an Ask a Model block, which asks the model from Settings › Assistant once. Blocks can be grouped under a title and coloured.
  • Responses can be checked against the request's GraphQL schema.
  • The MCP Servers page lists resource templates, with a field for each variable. A server's sampling request can be answered by your model, and you read the answer before it goes back.

Improved

  • WebSocket, Socket.IO and GraphQL subscriptions send the request's auth with the upgrade (Hawk, OAuth 1.0, EdgeGrid, AWS, Digest). MQTT publishes carry 5.0 properties.
  • Automatic headers such as User-Agent, Accept and Cookie can be switched off per request. The Settings tab shows only what the request's kind uses. Copy as cURL and Generate Code include Hawk, OAuth 1.0 and EdgeGrid signatures.
  • The Assistant's tool calls live in a tray behind the composer. The conversation keeps only the words.
  • A copy of a workspace asks before it uses the original's secrets and permissions.
  • Quick Send (the menu bar panel) is removed. The Shortcuts actions stay.

Fixed

  • Two security audits: hostile responses, specs and servers can no longer crash or hang Echolot, redirects no longer carry secrets to other hosts, and agents see only what the safety model allows.
  • Fixed edits lost on a reload or quit, slow opening of large JSON and long lines, sheets in Marine, and the onboarding tour.
